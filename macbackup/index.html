Privacy policy

Personal backup utility

Selected Mac files, backed up to the owner's cloud.

macbackup runs locally on a Mac. It uses rclone to copy selected folders and files directly to cloud storage accounts controlled by the owner.

How it works

The owner chooses the files to back up, the files to exclude, and which files to encrypt before transfer. Readable backups can be consulted through Google Drive. Private backups are encrypted locally using rclone crypt.

Previous versions are kept in a backup history. The owner controls the backup configuration and removal of stored copies.

Google Drive access

The application uses Google OAuth to obtain permission to manage backup files authorized to the application, using the drive.file scope. This access is used to create, read, update and delete the backup files managed by macbackup.

Google authorization takes place in the browser. Backup transfers go directly between the owner's Mac and the configured storage provider.
