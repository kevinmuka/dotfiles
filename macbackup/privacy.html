About the application

Privacy policy

macbackup is a personal backup utility that runs on the owner's Mac and uses rclone to store selected files in the owner's configured cloud accounts.

Data accessed and purpose

The tool accesses local files selected by the owner and the cloud backup files it manages. It uses file names, paths, sizes, timestamps and integrity information to plan and perform transfers, retain previous versions and recover data.

Google Drive access uses the OAuth scope https://www.googleapis.com/auth/drive.file. Google data is used to create, list, read, update and delete backup files authorized to the application.

Where data is stored

Selected backup data is transferred directly from the owner's Mac to the configured storage provider, including Google Drive when enabled. Readable backup files remain readable in the owner's account. Files assigned to the private area are encrypted on the Mac with rclone crypt before upload.

OAuth credentials are kept in rclone's local configuration. The owner may include that configuration in an encrypted backup. Encryption keys are managed by the owner.

Sharing and use

Backup data is processed for the owner's backup and recovery purposes. It is not sold, used for advertising, or used to train machine learning models. Data is sent to the storage providers selected by the owner and remains subject to those providers' policies.

The public informational pages contain the application description, this policy and a support contact. They do not provide access to the owner's backups, OAuth tokens or encryption keys.

Retention and deletion

Backup history is retained until the owner removes it. Excluding a path from future backups does not automatically remove existing copies or previous versions. The owner can manage stored files through the storage provider and supported backup tools.

Moving a file to a provider's trash is distinct from permanently deleting it. Retention and recovery within a provider's trash follow that provider's policies.

Revoking Google access

The owner can revoke the application's Google access through Google Account connections. Revocation stops authorized access by the application; existing backup files remain in the owner's Drive until removed by the owner.
