Neovim / editor

Small core. Room to grow.

The Neovim configuration is a separate submodule with a predictable startup path: core behavior first, plugins through lazy.nvim, then theme and custom interface components.

Startup path

Know where a change belongs.

Configuration is split by responsibility, so editor options and mappings do not have to live beside plugin specifications.

01 / CORE

Editor behavior

Options, mappings, custom commands and events are loaded from small modules.

02 / PLUGINS

lazy.nvim

Plugin specs declare triggers, dependencies and configuration close to the plugin itself.

03 / INTERFACE

Theme & winbar

A shared palette and a custom winbar complete the interface after the core is ready.
