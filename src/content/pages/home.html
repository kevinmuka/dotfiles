The structure

One source, explicit boundaries.

The repository stores configuration. The symlink manager connects it to the home directory. The backup tool independently selects what should reach cloud storage.

SOURCE / 01

Repository

home/ mirrors paths below the home directory. Neovim is tracked as a separate submodule.

LINK / 02

Local setup

dot.sh links managed paths and reports conflicts before replacing anything.

BACKUP / 03

Cloud copy

macbackup applies its own plain, private, exclusion and history rules.
